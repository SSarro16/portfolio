# Simone Sarro Portfolio

Personal developer portfolio built with React, TypeScript and Vite.

## Features

- React + TypeScript
- Vite
- Responsive UI
- Italian / English language switch
- Project cards with GitHub/demo links
- Code-inspired design system
- Deploy-ready static webapp

## Getting started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Typecheck

```bash
npm run typecheck
```

## Project structure

```txt
public/
  favicon.png
src/
  components/
  data/
  i18n/
  styles/
  App.tsx
  main.tsx
```

## Deployment

This is a static Vite application. Build output is generated in `dist/` and can be deployed on static hosts such as Render, Netlify, Vercel or GitHub Pages.

## Public data

The public UI intentionally uses email and GitHub as the main contact channels. No backend, private CV file, API keys or environment files are required for this portfolio.
